Conway's Game of Life

A small Unity coding project that starts with one Gemini prompt, then follows up with a camera fix so the simulation fills the game view.

Chapter 1: Create the simulation script

The first prompt was direct: make John Conway's Game of Life in Unity. Gemini returned a C# script that creates a texture, treats each pixel as a cell, randomizes the starting grid, and updates the board with the Game of Life rules.

Source conversation: Google AI Mode share link

Step 1: Set up the Unity object

In a 2D Unity project, create an empty GameObject named Simulation. Then create a C# script named GameOfLife and attach it to that object.

Step 2: Add the first script

 </>  C#
using UnityEngine;

public class GameOfLife : MonoBehaviour
{
    public int width = 100;
    public int height = 100;
    public float timeStep = 0.1f;

    private Texture2D texture;
    private Color[] currentGrid;
    private Color[] nextGrid;
    private float timer;

    void Start()
    {
        texture = new Texture2D(width, height)
        {
            filterMode = FilterMode.Point
        };

        Sprite sprite = Sprite.Create(texture, new Rect(0, 0, width, height), new Vector2(0.5f, 0.5f));
        GameObject go = new GameObject("GridRenderer");
        go.AddComponent<SpriteRenderer>().sprite = sprite;

        currentGrid = new Color[width * height];
        nextGrid = new Color[width * height];

        RandomizeGrid();
    }

    void Update()
    {
        timer += Time.deltaTime;

        if (timer >= timeStep)
        {
            timer = 0f;
            CalculateNextGeneration();
        }
    }

    void RandomizeGrid()
    {
        for (int x = 0; x < width; x++)
        {
            for (int y = 0; y < height; y++)
            {
                bool isAlive = Random.value > 0.5f;
                currentGrid[y * width + x] = isAlive ? Color.white : Color.black;
            }
        }

        texture.SetPixels(currentGrid);
        texture.Apply();
    }

    void CalculateNextGeneration()
    {
        for (int x = 0; x < width; x++)
        {
            for (int y = 0; y < height; y++)
            {
                int aliveNeighbors = CountAliveNeighbors(x, y);
                int index = y * width + x;
                bool isAlive = currentGrid[index] == Color.white;

                if (isAlive)
                {
                    if (aliveNeighbors < 2 || aliveNeighbors > 3)
                        nextGrid[index] = Color.black;
                    else
                        nextGrid[index] = Color.white;
                }
                else
                {
                    if (aliveNeighbors == 3)
                        nextGrid[index] = Color.white;
                    else
                        nextGrid[index] = Color.black;
                }
            }
        }

        Color[] temp = currentGrid;
        currentGrid = nextGrid;
        nextGrid = temp;

        texture.SetPixels(currentGrid);
        texture.Apply();
    }

    int CountAliveNeighbors(int x, int y)
    {
        int count = 0;

        for (int i = -1; i <= 1; i++)
        {
            for (int j = -1; j <= 1; j++)
            {
                if (i == 0 && j == 0) continue;

                int nx = x + i;
                int ny = y + j;

                if (nx < 0) nx = width - 1;
                if (nx >= width) nx = 0;
                if (ny < 0) ny = height - 1;
                if (ny >= height) ny = 0;

                int index = ny * width + nx;
                if (currentGrid[index] == Color.white)
                {
                    count++;
                }
            }
        }

        return count;
    }
}

Step 3: Run the scene

Press Play in Unity. The simulation should create a GridRenderer object and show a randomized black-and-white cellular field that evolves over time.

Chapter 2: Fit the camera to the grid

The first version worked, but the projected play area appeared too small. The second prompt asked how to sync the play area to the camera. The fix is to create the sprite at one pixel per Unity unit and then size the orthographic camera from the grid dimensions.

Step 1: See the camera problem

The simulation worked, but the grid rendered as a tiny square inside a much larger camera view. That made it hard to see the cells clearly, so the next change fits the camera to the generated sprite.

Step 2: Replace the Start method

void Start()
{
    texture = new Texture2D(width, height)
    {
        filterMode = FilterMode.Point
    };

    Sprite sprite = Sprite.Create(
        texture,
        new Rect(0, 0, width, height),
        new Vector2(0.5f, 0.5f),
        1f
    );

    GameObject go = new GameObject("GridRenderer");
    go.AddComponent<SpriteRenderer>().sprite = sprite;

    currentGrid = new Color[width * height];
    nextGrid = new Color[width * height];

    RandomizeGrid();
    FitCameraToGrid();
}

Step 3: Add FitCameraToGrid

 </>  C#
void FitCameraToGrid()
{
    Camera mainCam = Camera.main;
    if (mainCam == null) return;

    mainCam.transform.position = new Vector3(0, 0, -10);
    mainCam.orthographic = true;

    float screenRatio = (float)Screen.width / Screen.height;
    float gridRatio = (float)width / height;

    if (screenRatio >= gridRatio)
    {
        mainCam.orthographicSize = height / 2f;
    }
    else
    {
        mainCam.orthographicSize = (width / 2f) / screenRatio;
    }
}

The important new line is FitCameraToGrid();. It is now enabled as the last line of Start(), after the grid is created and randomized, so the camera can resize itself when the scene begins.

Step 4: Verify the camera fix

Run the scene again and check that:

  • The Main Camera is orthographic.
  • The camera is centered at (0, 0, -10).
  • The simulation fills the game view instead of sitting as a tiny square.
  • The cell edges stay crisp because the texture uses point filtering.
